# НЕ ЖАЛЬ / NO STING

Двомовний інтерактивний **сайт-комікс про бджіл** у стилі Гая Річі: кримінальна сага одного
вулика, де народні міфи «від дідів-прадідів» розвінчуються науковими доказами.
**Жоден факт без DOI.**

> Усе, що ти знаєш про бджіл, тобі розказав дід. А дід не читав PubMed.

## Що всередині
- **Холодний відкрив** + перемикач мов UK/EN і тумблер руху.
- **Швидкий вердикт (TL;DR)** — усі пари «вулиця vs наука» одним списком з якорями.
- **5 глав-«справ»:** Знайомство з фірмою (каст) · Шифр (танець) · Справа про мед ·
  Ворог у домі (Varroa) · Діди-прадіди (монтаж міфів).
- **Механіка на кожному твердженні:** ЩО КАЖЕ ВУЛИЦЯ → ЩО КАЖЕ НАУКА + чип «джерело» з DOI,
  бейдж доказовості, картка «НЕ ВСЕ ТАК ПРОСТО» для спірного, червоне ЗАСТЕРЕЖЕННЯ (ботулізм).
- **Стіна ДЖЕРЕЛА** — усі 16 цитованих праць із посиланнями.

## Ілюстрації
Фінальний арт — 25 нуарних панелей (портрети каст, схеми, заставки глав, hero),
покладених у `assets/panels/` як WebP в єдиному нуар-стилі. Під кожним растром лишається
кодовий SVG-фолбек, тому сайт працює і без картинок.
Історично весь арт був кодом: **5 портретів касту**, де різниця в морфології, а не в
кольорі (усі проходять силует-тест), і **14 пояснювальних схем-«доказів»**: геометрія
танцю-виляння, спектр зору бджоли, Varroa і жирове тіло, анатомія жала, зимовий клуб,
консервація меду, ланцюг ботулізму, конкуренція з дикими бджолами та інші.
Правило: якщо картинка не пояснює — її немає. Повний перелік і критерій
силует-тесту — у `docs/ILLUSTRATIONS.md`.

## Запуск
```bash
python3 -m http.server 8000
# відкрий http://localhost:8000
```
Сайт самодостатній: без фреймворків, білд-кроку й зовнішніх CDN. Відкривається і як `file://`.

## Перевірка цілісності
```bash
node tools/check.mjs
```
Падає, якщо є факт без DOI, неперекладений рядок або спірне твердження без картки «не все так просто».

Мобільні скріншоти та JS-проби з емуляцією пристрою (справжні 320–412 px, touch, DPR):
```bash
node tools/shot-cdp.mjs http://localhost:8000/ shot.png --w=375 --h=812 --anchor=ch1
```

## Технології
Vanilla HTML/CSS/JS · CSS custom properties · IntersectionObserver · self-hosted woff2
(Oswald + JetBrains Mono, з кирилицею) · SVG halftone/зерно · доступність (reduced-motion,
клавіатура, ARIA, контраст AA).

## Структура репозиторію
```
index.html    — оболонка сторінки, підключення стилів і скриптів
js/           — дані, рушій і SVG-фігури (детально — docs/ARCHITECTURE.md)
styles/       — CSS за призначенням: токени, база, компоненти, фігури, анімації, адаптивність
assets/       — шрифти, favicon, WebP-панелі ілюстрацій
tools/        — Node-скрипти перевірки, збірки й рендеру (детально — tools/README.md)
docs/         — архітектура та довідник ілюстрацій
```

## Відомі обмеження
Скрипти підключені звичайними `<script>` без `type="module"`, тому обмінюються
станом через глобальні об'єкти, а не `import`/`export` — деталі й причина в
`docs/ARCHITECTURE.md`. Растрові панелі (`assets/panels/`, ≈16 МБ) закомічені
напряму, без Git LFS.
