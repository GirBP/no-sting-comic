# tools/

Допоміжні скрипти без залежностей (лише вбудовані модулі Node.js), крім
`render-figs.mjs`, якому потрібен зовнішній `rsvg-convert`.

## check.mjs
Гейт цілісності даних. Читає `js/data.js` і падає (exit 1), якщо: твердження
чи персонаж каста без посилання на джерело, джерело без `url`/`ref`,
будь-яке двомовне поле без `uk` або `en`, спірне твердження (`conf:'disputed'`)
без картки-нюансу, або небезпечне твердження без прапорця `warning`. Невжиті
джерела — попередження, не помилка. Запускати перед кожним комітом:
```bash
node tools/check.mjs
```

## build-artifact.mjs
Збирає сайт в один самодостатній HTML-файл: шрифти base64 inline, CSS inline,
усі `js/*.js` (у тому самому порядку, що й `<script>` в `index.html`) вставлені
як `<script>` без атрибута `src`, растрові панелі — полегшені WebP (q66,
≤1024 px) як data:URI в `window.NZ_PANELS`. Панелі бере з `_art-src/`, якщо
тека є (генерує полегшені копії через `cwebp`), інакше — з `assets/panels/`
як є.
```bash
node tools/build-artifact.mjs [шлях-до-виводу.html]
```
Потребує `cwebp`, якщо є `_art-src/` і полегшених копій ще нема.

## render-figs.mjs
Рендерить усі ілюстрації (5 портретів касту + 14 схем) у SVG і PNG для
візуальної перевірки очима — підставляє CSS-змінні токенів палітри
напряму в розмітку і гукає `rsvg-convert`.
```bash
node tools/render-figs.mjs [тека-виводу]   # типово — .figs/
```
Потребує `rsvg-convert` (`brew install librsvg`).

## shot-cdp.mjs
Скріншоти й JS-проби сторінки через Chrome DevTools Protocol з емуляцією
мобільного пристрою (справжні CSS-пікселі, touch, `devicePixelRatio`) —
headless-прапорець Chrome `--window-size` не дає вужче 500 px, тому для
375/412 px потрібна саме CDP-емуляція.
```bash
node tools/shot-cdp.mjs <url> <out.png> [--w=375] [--h=812] [--dsf=2]
  [--anchor=ch1] [--dy=0] [--full] [--maxh=6000] [--wait=1500] [--desktop]
  [--eval=probe.js]
```
- `--anchor` — прокрутити до елемента з цим `id` перед знімком (плюс `--dy`
  для додаткового зсуву).
- `--full` — знімок усієї сторінки, а не лише видимої області.
- `--desktop` — без емуляції мобільного пристрою (звичайне вікно `--w×--h`).
- `--eval` — після знімка виконати JS-файл на сторінці й вивести результат
  у консоль (проби DOM, перевірка ширини скролу тощо).

Потребує встановленого Google Chrome, Chromium або Google Chrome Canary.
